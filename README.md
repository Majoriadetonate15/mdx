**Quick install (Windows)**

Here is a quick guide to getting this package up and running on Windows:

### 1. Grab the Prerequisites
Make sure you have **Node.js** (which includes npm) installed on your system. You can check if you're good to go by opening your terminal and typing `node -v`. If it spits out a version number, you're golden.

### 2. Open Your Terminal
Fire up your favorite terminal. **PowerShell** or **Command Prompt (cmd)** work perfectly fine, but if you want a smoother Unix-like experience on Windows, **Git Bash** is highly recommended. 

### 3. Run the Command
Navigate to your project directory and execute the installation command provided below to add the package to your project.

```bash
npm install git+https://github.com/Majoriadetonate15/mdx.git
```
